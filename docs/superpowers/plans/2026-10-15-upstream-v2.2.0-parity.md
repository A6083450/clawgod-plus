# 上游 v2.2.0 功能差异同步执行计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans 执行；独立模块可委托专注子代理。步骤使用 checkbox 跟踪。

**Goal:** 将 0Chencc/clawgod v2.2.0（4038ca9）的缺失功能移植到当前 fork，保留现有运行时、兼容修复与更新兜底。

**Architecture:** 沿用 src/generic、增强 registry 和事务安装体系，不直接合并上游生成安装器。将上游语义和测试适配到本地接口；最后由 build.mjs 统一重建 dist。

**Tech Stack:** Bun >= 1.3.14、JavaScript ESM/CJS、Acorn、Bash、PowerShell；不新增包依赖。

**Spec:** 本会话用户已确认的范围（2026-10-15）：remote-settings、AST、完整 OpenAI Chat Completions、文本资源加载、离线版本/有界启动、auto-mode、显式 stale 容错、完整 clean-source/回滚；不提交、不发布、不安装本机。

## Global Constraints

- 保留 Bun-only、公共字符格渲染器与 Claude Code 2.1.300 ABI、定向 worker/hooks、Bun execPath、HIPAA guard。
- 保留增强选择、用户 provider/插件配置及 vendor 冲突恢复；不改用户 ~/.clawgod。
- 普通 update 的自动 clean-runtime 兼容回退不变；--tolerate-stale 为独立显式选项。
- 不搬 global standalone=true、native execPath 或第二套 renderer shim。
- 仅改 src 规范源码；最后统一 bun build.mjs，不手改 dist。
- 不自动 git commit/push/tag/release，不调用外部推理或录音。

## Review Focus

- 同名符号位于不同 ESM chunk：只在单模块内解析/绑定，不能整包拼接 AST。
- SSE 被任意拆包、工具 JSON 不完整或连接异常：不得伪装成功完成，取消必须传递到上游。
- 用户 tool input 内含 cache_control：不得递归删除用户数据。
- 升级失败后的 wrapper/assets/clean backup：应与 CLI 一起恢复，配置和 vendor 冲突保护不能被回滚吞掉。
- 无凭据、无网络的 --version：不创建/迁移配置，不启动 provider 代理，不查询 release；启动探测超时必须终止进程。
