# 自动更新选择与本机发布

用户已授权：完成自动检测、安装/稍后/跳过版本，发布新版本并安装到本机。

- 复用 self-update.cjs 和 .update-check，不新增运行时文件、后台常驻服务或依赖。
- 仅无任务参数的 TTY 交互启动检查（允许自动注入 --chrome）；GitHub 正式 Release 两安装器资产齐全才提供选择。24 小时缓存，单次联网 3 秒超时，失败继续启动。
- 按完整 ClawGod tag 比较，包含同一天 Claude 版本和修订号；跳过只针对一个精确 Release，手动 update 不受影响。
- 安装选择调用现有无参 updater（新安装器决定已验证 Claude 版本），结束后退出并提示重新启动，避免旧进程加载一半新运行时。
- 默认已验证 Claude Code 仍 2.1.302；Release v2026.10.19-claude.2.1.302。
- 先验证本地全量、全增强隔离 E2E、菜单 PTY；独立审查；提交推送触发兼容 CI，通过后推 tag 发布。
- 核验 Release 安装器与本地除 SELF_VERSION 外字节一致；备份 ~/.clawgod 和受管启动器，隔离 cmux shim 路径后安装；核对用户配置哈希、版本与交互启动。
- 不删除历史备份，不改 Provider 凭据，不启用未经验证的上游版本。
